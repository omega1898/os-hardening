## Objective

Develop an automated tool to cyber harden platforms built on a Linux operating system.

## Description

Hardening Navy platforms is labor intensive, especially autonomous and unmanned systems that run a Linux distribution. The effort is limited to the Linux OS. The tool should determine which OS functions a given platform actually needs, remove the rest (including debloating), and configure what remains to improve security without breaking required functions. The performer chooses the demonstration platform, preferably a commercial or open-source autonomous vehicle. Proposals must include metrics for the improvement.

## Phase I

Define a conceptual software architecture that uses runtime information to find the minimal required OS functions, then recommends or applies removal and security configuration. Demonstrate it on a representative platform and show an improvement in security posture, for example through code analysis or penetration testing. Approaches are compared on how completely they harden and how they ingest information sources.

## Phase II

Build a functional prototype and work with Navy platform owners to guide and test it. Show it can ingest sources such as specifications, test plans and other tools' outputs, and harden and minimize the OS on a Navy platform. Navy personnel will measure code reduction, configuration, debloating, code analysis and penetration-test results. Prepare a Phase III transition plan.

## Phase III and dual use

Transition to Navy use. Commercial Linux-based products, such as IoT and smart-home devices, need the same hardening.
