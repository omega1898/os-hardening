# Posted topic Q&A: DON27BZ02-NV010 (summary)

Summarized from the public topic page ([navysbir.com](https://www.navysbir.com/n27_2/DON27BZ02-NV010.htm), read Nov 24, 2026). The official Q&A is in DSIP and stays open to new questions until Dec 16, 2026, 12:00 PM ET.

## Set 1 (Nov 4, 2026)

- **Zero-trust layer for data and process access?** Out of scope; the focus is the Linux OS only.
- **Which distributions, kernels, build systems and architectures for Phase II?** No government-furnished equipment; the choice is the proposer's.
- **Is any metric weighted more? Preferred baseline such as DISA STIGs or CIS?** The proposer decides what to include and must justify it.
- **Fully automatic or human-approved?** Minimize human time and automate as much as possible; explain the choice.

## Set 2 (Nov 15, 2026)

- **Boot chain (bootloader, Secure Boot, kernel config) in scope? Custom minimal kernel acceptable?** Justify the boot-chain scope you choose.
- **Two use cases:** a Navy-controlled platform, and a commercial platform analyzed without design material.
- **Must it survive OS updates?** Expect the tool to be run many times over the platform's life because of updates.

## Set 3 (Nov 17, 2026)

- **Which platform?** None is specified; pick one suited to a low-budget, short Phase I.
- **How is hardening scored and proven?** Explain why your approach hardens the OS with little manual labor, and how you score and prove it.
- **Government equipment?** Most likely none in Phase II, but there will be a collaborating Navy partner, named in Phase II.
